# uhcPortal-agent-dev

Development workspace for AI agent skills, rules, prompts, and tooling used with [uhc-portal](https://github.com/RedHatInsights/uhc-portal) (OCM UI).

## Purpose

This repository holds experimental and shared agent configuration for OpenShift Cluster Manager UI work — Cursor rules, skills, prompts, and related docs — separate from the production application codebase.

## Related

- Application: [RedHatInsights/uhc-portal](https://github.com/RedHatInsights/uhc-portal)
- Product: OpenShift Cluster Manager (console.redhat.com `/openshift`)
